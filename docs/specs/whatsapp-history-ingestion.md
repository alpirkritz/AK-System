# Ingest WhatsApp history sync, not just live messages

## Goal

כשהגשר מתנתק — תקלת סשן, קישור מחדש, או פריסה — כל ההודעות מאותו חלון נעלמות לתמיד. WhatsApp **כן** שולח היסטוריה למכשיר מקושר חדש, אבל הגשר מתעלם ממנה. המטרה: לכתוב גם את ההיסטוריה הזו, כך שניתוק לא יהפוך לחור בנתונים.

## Current behaviour (אומת בקוד)

`apps/whatsapp-bridge/src/whatsapp-client.ts:86-89`:

```ts
ev.on('messaging-history.set', ({ contacts, chats }) => {
  upsertContacts(contacts)
  noteChatTs(chats)
})
```

המטפל קורא רק אנשי קשר וחותמות זמן של שיחות ו**משליך את מערך ההודעות**. רק `handleInboundMessage` כותב, והוא מופעל מ-`messages.upsert` — כלומר הודעות חיות בלבד. בפועל, אחרי הקישור מחדש ב-6 באוקטובר הלוג הראה 14 אירועי `got history notification` עם `progress` עד 100 — היסטוריה הגיעה במלואה ונזרקה.

זה הסיבה שבקשת ההתחייבות מעדי, שנשלחה לפני 2026-10-05T08:56Z, לא ניתנת לשחזור.

## User stories

1. אחרי שהגשר היה מנותק, ההודעות מהחלון שהוחמץ נכנסות למערכת ואני לא מאבד אותן.
2. הודעה שכבר נקלטה חיה לא נכתבת שוב כשההיסטוריה מגיעה.
3. ההיסטוריה לא מפעילה תשובות אוטומטיות ולא התראות — היא נתונים, לא אירועים.

## Acceptance criteria

- [ ] הודעות מ-`messaging-history.set` נכתבות דרך אותו נתיב התמדה של הודעות חיות, בכפוף לאותן רשימות לכידה (קבוצות מנוטרות, allowlist לשיחות פרטיות).
- [ ] **אין כפילויות:** הודעה שכבר קיימת לפי `wa_message_id` לא נכתבת שוב.
- [ ] ההיסטוריה **לא** מפעילה תשובה אוטומטית, לא קוראת ל-Hugo ולא מייצרת התראות — נבדק במפורש.
- [ ] ההיסטוריה לא מפעילה סיווג התחייבויות בזמן הקליטה; היא זמינה לסריקה אחר כך כמו כל הודעה אחרת.
- [ ] חלון ההיסטוריה מוגבל ל-**3 יום** — הודעות ישנות מזה נזרקות, כדי שקישור מחדש לא ישפוך ארכיון שלם.
- [ ] כתיבת היסטוריה נרשמת ביומן עם מספר ההודעות שנכתבו ומספר אלו שדולגו ככפילות.

## Data model changes

אין טבלאות חדשות. `whatsapp_messages` ו-`whatsapp_dm_messages` כבר נושאות `wa_message_id`, שהוא המפתח לדה-דופליקציה. נדרש לוודא שקיים אינדקס ייחודי עליו — אם לא, להוסיף, כולל bootstrap ל-SQLite.

## API shape

אין נקודות קצה חדשות. ההודעות ההיסטוריות נוסעות באותם webhooks קיימים (`/api/whatsapp/messages`, `/api/whatsapp/dm`) בתוספת דגל שמסמן שהמקור הוא סנכרון היסטוריה, כדי שצד האפליקציה יוכל לדלג על תגובות ועל התראות.
