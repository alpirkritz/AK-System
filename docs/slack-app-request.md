# Slack App — בקשת אישור ארגוני

## מה

אפליקציה פנימית, *לקריאה בלבד*, בשם **AK**.  
מותקנת ב-Workspace יחיד. **אינה שולחת הודעות, אינה כותבת לשום ערוץ.**

## הרשאות נדרשות

| Scope | מה מאפשר |
|---|---|
| `channels:read` | רשימת ערוצים ציבוריים |
| `channels:history` | קריאת הודעות מערוצים ציבוריים שהאפליקציה הוזמנה אליהם |
| `groups:read` | רשימת ערוצים פרטיים שהאפליקציה הוזמנה אליהם |
| `groups:history` | קריאת הודעות מערוצים פרטיים שהאפליקציה הוזמנה אליהם |
| `users:read` | שמות משתמשים לתצוגה |
| `users:read.email` | התאמת חשבונות ל-CRM לפי אימייל |

אין `chat:write`, אין DM, אין הרשאות ניהול.

## תהליך ההתקנה

1. אני (המשתמש) יוצר App פנימי ב-[api.slack.com/apps](https://api.slack.com/apps).
2. מגדיר את ה-Scopes הנ"ל + Events API.
3. שולח בקשת התקנה → Admin מאשר.
4. אחרי אישור, מזמין את האפליקציה ידנית **רק לערוצים שנבחרו** (ציבורי: `/invite @AK`; פרטי: מהגדרות הערוץ).

## למה

המערכת האישית שלי (AK System) קוראת הודעות מהערוצים שנבחרו כדי לעזור לי לעקוב אחר התחייבויות ופריטים שדורשים מענה — בדיוק כמו שהיא קוראת וואטסאפ. אין עיבוד נתון ארגוני מחוץ לשרת הפרטי שלי.

## URLs (נדרשים להתקנה)

יסופקו בעת הגדרת ה-App:
- OAuth Redirect URI: `https://<domain>/api/slack/oauth/callback`
- Events API Request URL: `https://<domain>/api/slack/events`
