## What's built

**Schema** (`packages/database/src/schema.pg.ts` + `schema.ts`, mirrored, plus SQLite bootstrap in `index.ts`): new `voice_prints` table (one row: Alpir's enrolled voiceprint); `voice_recordings` gets `diarizationStatus`, `diarizationError`, `source` (`live`/`imported`); `voice_recording_people` gets `matchedAutomatically` + `confidence`.

**Self-voice matching** (`packages/api/src/services/audio-features.ts`, `voice-diarization.ts`): self-hosted, no external vendor, per the approved spec. ffmpeg decodes any input format to PCM; a hand-rolled log-mel + cosine-similarity heuristic (not a trained neural embedding — documented as such in the code) does voice-activity segmentation and self/other classification. Wired into `voice.ts`'s existing `processVoiceRecording` pipeline as a best-effort step after transcription: on a match, Alpir is auto-added to `voice_recording_people` (`matchedAutomatically: true`) — the transcript's own "דובר 1/2" labels are untouched (rewriting those would need frame-accurate diarization Gemini doesn't provide; auto-tagging the participant list was the safer, still-useful scope). Everyone else stays manually tagged, as decided. New tRPC procedures `voice.enrollVoicePrint` / `getVoicePrintStatus` / `deleteVoicePrint`.

**Storage decision**: confirmed self-hosted on the existing EC2 box — `deploy/Dockerfile.runtime` now installs `ffmpeg`. No new vendor, no retention/auto-delete change (kept as-is, per instruction).

**Android background recording** (`apps/mobile/app.config.ts`, `record.tsx`): `expo-audio`'s `enableBackgroundRecording: true` (adds the Android foreground-service permissions + service declaration); the `AppState`-triggered pause-on-background is now skipped on `Platform.OS === 'android'` only — iOS keeps today's pause behavior, out of scope per the spec. `allowsBackgroundRecording` is set on the Android audio session at recording start.

**Phone-call import** (`apps/mobile/app/(tabs)/import-recording.tsx`, new `expo-document-picker` dependency, Android `SEND`/`audio/*` intent-filter in `app.config.ts`): picks an existing audio file, shows its own consent step, uploads with `source: 'imported'`. Server's mime allowlist (`packages/api/src/services/voice.ts`) now also accepts `audio/3gpp`, `audio/3gpp2`, `audio/amr` (Samsung call-recorder formats).

**Voiceprint enrollment UI** (`apps/mobile/app/(tabs)/settings/voice-print.tsx`): records a ~20-30s sample, shows enrolled/not-enrolled status, re-enroll and delete.

**Web** (`apps/web/src/app/voice/lib/use-recorder.ts`, `page.tsx`): Screen Wake Lock requested on recording start, released on stop, re-acquired on tab-visibility return; graceful no-op if unsupported. Inline copy tells the user recording survives a tab switch but not full system sleep.
